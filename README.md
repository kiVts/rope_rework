# Realistic Ropes

[![Join Discord](https://img.shields.io/badge/Join-Discord-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.gg/bX4RzunsxC)

Reworks ropes, hoses and cables with gravity, material tension and floor/deck support.

**Rope behavior:** Rope can sag, slide over decks, lift off the ground and tighten as slack is taken up. Length stops avoid a bungee-like recovery pull. This release fixes sideways instability during payout and the kick when attaching a held rope to an anchor.

**Limitations:** Ropes pass through walls, vehicle sides and undersides; obstacle wrapping is disabled. Narrow ledges can be missed. Install and enable this mod on every multiplayer peer. A joining player may occasionally need a rope reconnected before it becomes visible.
